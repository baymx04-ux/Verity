# Product Roadmap

## Q4 FY2026 themes
1. Retrieval quality: hybrid search, better reranking, and citation checks.
2. SQL guardrails: read-only enforcement, row limits, and query explanations.
3. Administration: group management, audit export, and retention controls.
4. Reliability: ingestion retries, queue visibility, and clearer failure states.

## In discovery
- Connector framework for shared drives.
- Answer feedback loops and evaluation dashboards.
- Fine-grained field-level access for SQL results.

## Not planned
We are not building a general-purpose web browser agent or an unrestricted code execution environment. Customer data stays inside approved systems.

## How to use this
Dates are intentionally omitted. Priorities can change after customer research and security review. Do not promise a delivery date to a customer without confirmation from product and engineering leadership.
